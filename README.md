# Smart Contract Auditor (Hosted Project)

This repository is split into two independent modular packages: `frontend/` and `backend/`.

## Folder Structure

- `frontend/`: React + Vite web application containing UI components, styling, and client pipeline stages.
- `backend/`: Express server handling secure Gemini AI API integration, analysis engines, security detectors, and tests.

For detailed setup instructions on running each folder separately, refer to:
- [Frontend README](frontend/README.md)
- [Backend README](backend/README.md)
