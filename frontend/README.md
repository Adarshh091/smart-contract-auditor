# Smart Contract Auditor - Frontend

React-based web UI for the Smart Contract Auditor platform.

## Features
- Interactive 7-stage auditing pipeline UI.
- Browser-based Solidity compilation and AST visualizer.
- Findings drawer, severity filtering, and report exporter.
- Connects to the backend server via proxy for Gemini AI semantic analysis.

## Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

## Setup & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```
   The application will start on `http://localhost:5173`.

3. **Build for Production:**
   ```bash
   npm run build
   ```
